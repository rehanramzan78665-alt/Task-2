# Don't Take the Bait --- Phishing Awareness

An interactive phishing-awareness website built with **HTML, CSS, and
JavaScript**. It teaches users how to recognize suspicious messages,
identify fake websites, understand social-engineering tactics, and
respond safely to potential phishing attempts.

## Features

-   Explains common types of phishing, including email phishing, spear
    phishing, smishing, vishing, and QR-code phishing.
-   Teaches users to examine sender addresses, links, urgent wording,
    and suspicious attachments.
-   Includes an interactive example email where users can select red
    flags and read explanations.
-   Demonstrates how lookalike domains and fake login pages can mislead
    users.
-   Explains social-engineering tactics such as urgency, fear,
    authority, and trust.
-   Includes real-world incident examples.
-   Shares practical prevention tips and steps to take after a suspected
    phishing incident.
-   Provides an interactive multiple-choice quiz with feedback and a
    final score.
-   Supports navigation with Back/Next buttons and left/right arrow
    keys.
-   Uses responsive page styling.

## Requirements

-   A modern web browser
-   No installation, server, or build tools are required for basic use.

## How to Run

1.  Download or clone this repository.
2.  Open `Rehan_Task two.html.html` in a modern web browser.
3.  Use the **Back** and **Next** buttons or the left/right arrow keys
    to navigate.
4.  Try the interactive phishing-email exercise.
5.  Complete the quiz and review your score and feedback.

If you rename the file to `phishing_awareness.html`, open that filename
instead.

## Technologies Used

-   HTML5
-   CSS
-   JavaScript

## Learning Objectives

-   Recognize common phishing warning signs.
-   Understand how fake links and lookalike domains work.
-   Learn to verify unexpected requests through a separate trusted
    channel.
-   Practice safer password and multi-factor authentication habits.
-   Understand what to do after clicking a suspicious link or sharing
    credentials.

## Safety Note

This website is an educational awareness resource. If you suspect a real
phishing incident, follow your organization's security procedures and
report it to the appropriate support or security team.
